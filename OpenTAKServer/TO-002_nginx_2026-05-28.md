## 1. Doel

Dit document beschrijft de installatie en configuratie van nginx als reverse proxy voor OpenTAKServer (OTS). nginx fungeert als ingangspunt voor alle HTTP/HTTPS-verkeer en routeert verzoeken naar de interne Flask/gevent-applicatieserver op poort 8081. Tevens verzorgt nginx SSL-terminatie, WebSocket-proxying voor Socket.IO en de Marti API-eindpunten op poorten 8080 (HTTP) en 8443 (HTTPS).

## 4. Vereisten vooraf

- [ ] Ubuntu 22.04 of 24.04 LTS geinstalleerd en bijgewerkt (`apt update && apt upgrade`)
- [ ] OpenTAKServer geinstalleerd en actief op poort 8081 (intern)
- [ ] SSL-certificaten aangemaakt via OTS interne CA (zie TO-005) of extern CA
- [ ] Poorten 80, 443, 8080, 8443 bereikbaar in firewall (ufw of cloud security group)
- [ ] Root of sudo toegang aanwezig op de server
- [ ] DNS A-record of statisch IP beschikbaar voor de server
- [ ] `openssl` pakket geinstalleerd: `openssl version`
- [ ] Python/gevent OTS service actief: `systemctl status ots`

## 5. Procedure

### Stap 1: nginx installeren

| Veld | Inhoud |
|---|---|
| **Actie** | Installeer nginx via apt |
