## 1. Purpose

This document describes the installation and configuration of NGINX as a reverse proxy for OpenTAKServer (OTS). NGINX acts as the entry point for all HTTP/HTTPS traffic and routes requests to the internal Flask/gevent application server on port 8081. NGINX also handles SSL termination, WebSocket proxying for Socket.IO, and the Marti API endpoints on ports 8080 (HTTP) and 8443 (HTTPS).

## 4. Prerequisites

- [ ] Ubuntu 22.04 or 24.04 LTS installed and updated (`apt update && apt upgrade`)
- [ ] OpenTAKServer installed and running on port 8081 (internal)
- [ ] SSL certificates created via OTS internal CA (see TO-005) or external CA
- [ ] Ports 80, 443, 8080, 8443 accessible through firewall (ufw or cloud security group)
- [ ] Root or sudo access available on the server
- [ ] DNS A-record or static IP available for the server
- [ ] `openssl` package installed: `openssl version`
- [ ] Python/gevent OTS service active: `systemctl status ots`

## 5. Procedure

### Step 1 — Install NGINX

**Action:** Install NGINX via apt.

```bash
sudo apt update && sudo apt install -y nginx
```

**Expected Result:** NGINX installed, service active.

**Verification:** `nginx -v` shows version; `systemctl status nginx` shows `active (running)`.

---

### Step 2 — Prepare SSL certificates

**Action:** Copy the OTS CA certificate and server key to the NGINX location.

```bash
sudo mkdir -p /etc/nginx/ssl
sudo cp /etc/opentakserver/ssl/server.crt /etc/nginx/ssl/ots.crt
sudo cp /etc/opentakserver/ssl/server.key /etc/nginx/ssl/ots.key
sudo chmod 600 /etc/nginx/ssl/ots.key
```

**Expected Result:** Certificate and key present at `/etc/nginx/ssl/`.

**Verification:** `ls -la /etc/nginx/ssl/` shows both files.

---

### Step 3 — Configure NGINX virtual host

**Action:** Create OTS NGINX configuration at `/etc/nginx/sites-available/opentakserver`.

```nginx
server {
    listen 8080;
    server_name _;
    return 301 https://$host:8443$request_uri;
}

server {
    listen 8443 ssl;
    server_name _;

    ssl_certificate     /etc/nginx/ssl/ots.crt;
    ssl_certificate_key /etc/nginx/ssl/ots.key;
    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;

    # WebSocket support for Socket.IO
    location /socket.io/ {
        proxy_pass         http://127.0.0.1:8081;
        proxy_http_version 1.1;
        proxy_set_header   Upgrade $http_upgrade;
        proxy_set_header   Connection "upgrade";
        proxy_set_header   Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # All other requests
    location / {
        proxy_pass         http://127.0.0.1:8081;
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
    }
}
```

**Expected Result:** Configuration file created without syntax errors.

**Verification:** `sudo nginx -t` returns `syntax is ok` and `test is successful`.

---

### Step 4 — Enable the site and disable default

**Action:** Enable the OTS site and remove the default NGINX site.

```bash
sudo ln -s /etc/nginx/sites-available/opentakserver /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
```

**Expected Result:** OTS site enabled, default site removed.

**Verification:** `ls /etc/nginx/sites-enabled/` shows only `opentakserver`.

---

### Step 5 — Reload NGINX and verify

**Action:** Reload NGINX to apply the new configuration.

```bash
sudo systemctl reload nginx
```

**Expected Result:** NGINX reloads without errors.

**Verification:** `systemctl status nginx` shows `active (running)`; `curl -k https://localhost:8443/` returns a response from OTS.

## 6. Verification and Acceptance Criteria

| Criterion | Verification Method | Acceptance Value |
|---|---|---|
| NGINX service active | `systemctl status nginx` | `active (running)` |
| Config syntax valid | `nginx -t` | `syntax is ok` |
| Port 8443 responding | `curl -k https://localhost:8443/` | HTTP 200 or redirect from OTS |
| Port 8080 redirects to 8443 | `curl -v http://localhost:8080/` | HTTP 301 to HTTPS |
| WebSocket proxying works | Browser WebUI → live map | Map updates in real time |
| SSL certificate served correctly | `openssl s_client -connect localhost:8443` | Certificate chain shown, no errors |

---

## 7. Rollback Procedure

1. Disable the OTS NGINX site: `sudo rm /etc/nginx/sites-enabled/opentakserver`
2. Re-enable the default site if needed: `sudo ln -s /etc/nginx/sites-available/default /etc/nginx/sites-enabled/`
3. Reload NGINX: `sudo systemctl reload nginx`
4. If NGINX fails to start, check logs: `sudo journalctl -u nginx -n 50`
5. Restore previous config from backup if available.

## 8. Known Issues and Workarounds

| Issue | Circumstance | Workaround |
|---|---|---|
| WebSocket connection drops | Missing `Upgrade` header in proxy config | Ensure `proxy_http_version 1.1` and `Upgrade` headers are set |
| 502 Bad Gateway | OTS not running on port 8081 | Check `systemctl status ots`; ensure OTS is started before NGINX |
| SSL handshake failure in ATAK | Self-signed cert not trusted by client | Import OTS CA certificate into ATAK trust store |
| Port 8443 already in use | Another service using the port | Check `ss -tlnp | grep 8443`; stop conflicting service |
| Config changes not applied | Reload vs restart confusion | Use `systemctl reload nginx` for config changes; `restart` for binary updates |
