## 1. Doel

Dit document beschrijft de installatie en configuratie van RabbitMQ als berichtbroker voor OpenTAKServer (OTS). RabbitMQ verzorgt de asynchrone communicatie tussen de CoT-parser, WebSocket-clients (Flask-SocketIO), missiegegevens en groepsberichten. De correcte aanmaak van exchanges met bijbehorende typen en TTL-instellingen is essentieel voor de betrouwbare werking van het berichtensysteem.

## 5. Procedure

### Stap 1: Erlang en RabbitMQ repository toevoegen

| Veld | Inhoud |
|---|---|
| **Actie** | Voeg officiële RabbitMQ apt repository toe |
| **Commando** | Zie onderstaand script |
| **Verwacht resultaat** | Repository toegevoegd, packages beschikbaar |
| **Verificatie** | `apt-cache policy rabbitmq-server` toont versie uit officieel kanaal |

```bash
# Installeer vereiste tools
sudo apt-get install -y curl gnupg apt-transport-https

# Voeg Erlang repository toe
curl -1sLf 'https://dl.cloudsmith.io/public/rabbitmq/rabbitmq-erlang/setup.deb.sh' | sudo -E bash

# Voeg RabbitMQ repository toe
curl -1sLf 'https://dl.cloudsmith.io/public/rabbitmq/rabbitmq-server/setup.deb.sh' | sudo -E bash

# Update package lijst
sudo apt-get update -y
```

|---|---|

### Stap 5: OTS RabbitMQ gebruiker aanmaken

| Veld | Inhoud |
|---|---|
| **Actie** | Maak een dedicated RabbitMQ gebruiker aan voor OTS |
| **Commando** | `sudo rabbitmqctl add_user ots VERVANG_MET_STERK_WACHTWOORD` `sudo rabbitmqctl set_user_tags ots administrator` `sudo rabbitmqctl set_permissions -p / ots ".*" ".*" ".*"` |
| **Verwacht resultaat** | Gebruiker aangemaakt met volledige rechten op default vhost |
| **Verificatie** | `sudo rabbitmqctl list_users` toont `ots` met tag `[administrator]` |

| Veld | Inhoud |
|---|---|
| **Actie** | Verwijder de onveilige standaard guest gebruiker |
| **Commando** | `sudo rabbitmqctl delete_user guest` |
| **Verwacht resultaat** | guest account verwijderd |
| **Verificatie** | `sudo rabbitmqctl list_users` toont geen `guest` meer |

### Stap 7: Exchanges aanmaken

| Veld | Inhoud |
|---|---|
| **Actie** | Maak alle vereiste OTS exchanges aan via Management API |
| **Commando** | Zie onderstaand script |
| **Verwacht resultaat** | Alle 7 exchanges aangemaakt |
| **Verificatie** | Management UI op http://localhost:15672/#/exchanges toont alle exchanges |

```bash
#!/bin/bash
# OTS Exchange aanmaak script
RABBITMQ_USER="ots"
RABBITMQ_PASS="VERVANG_MET_STERK_WACHTWOORD"
MGMT_URL="http://localhost:15672/api"

declare -A EXCHANGES
# exchange_naam:type
EXCHANGES=(
  ["dms"]="direct"
  ["cot_parser"]="direct"
  ["chatrooms"]="direct"
  ["missions"]="topic"
  ["groups"]="topic"
  ["firehose"]="fanout"
  ["flask-socketio"]="fanout"
)

for EXCHANGE in "${!EXCHANGES[@]}"; do
  TYPE="${EXCHANGES[$EXCHANGE]}"
  echo "Aanmaken exchange: $EXCHANGE (type: $TYPE)"
  curl -s -u "$RABBITMQ_USER:$RABBITMQ_PASS" \
    -X PUT \
    -H "Content-Type: application/json" \
    -d "{
      \"type\": \"$TYPE\",
      \"durable\": true,
      \"auto_delete\": false,
      \"arguments\": {
        \"x-message-ttl\": 86400000
      }
    }" \
    "$MGMT_URL/exchanges/%2F/$EXCHANGE"
  echo ""
done

echo "Alle exchanges aangemaakt."
```

### Stap 8: TTL verificatie voor exchanges

| Veld | Inhoud |
|---|---|
| **Actie** | Controleer TTL instelling (86400000 ms = 24 uur) op exchanges |
| **Commando** | `curl -s -u ots:WACHTWOORD http://localhost:15672/api/exchanges/%2F/dms \| python3 -m json.tool` |
| **Verwacht resultaat** | JSON toont `"x-message-ttl": 86400000` in arguments |
| **Verificatie** | Alle 7 exchanges tonen correct TTL-argument |

### Stap 9: OTS configuratie bijwerken

| Veld | Inhoud |
|---|---|
| **Actie** | Stel RabbitMQ verbindingsgegevens in OTS config in |
| **Commando** | `sudo nano /etc/opentakserver/config.yml` |
| **Verwacht resultaat** | Configuratiebestand bijgewerkt |
| **Verificatie** | `sudo -u ots cat /etc/opentakserver/config.yml \| grep -i rabbit` |

Relevante configuratievelden in `/etc/opentakserver/config.yml`:
```yaml
OTS_RABBITMQ_SERVER_ADDRESS: "127.0.0.1"

OTS_RABBITMQ_SERVER_USERNAME: "ots"
OTS_RABBITMQ_SERVER_PASSWORD: "VERVANG_MET_STERK_WACHTWOORD"
```

## 7. Rollback procedure

1. Stop OTS om verbindingspogingen te stoppen:
   ```bash
   sudo systemctl stop ots
   ```
2. Verwijder aangemaakte exchanges via Management API of UI.
3. Verwijder OTS gebruiker indien nodig:
   ```bash
   sudo rabbitmqctl delete_user ots
   ```
4. Stop RabbitMQ indien volledig verwijderen gewenst:
   ```bash
   sudo systemctl stop rabbitmq-server
   sudo systemctl disable rabbitmq-server
   sudo apt-get remove --purge rabbitmq-server erlang-* -y
   ```
5. Herstel OTS configuratie naar vorige staat (RabbitMQ connectiegegevens verwijderen).

## 8. Bekende issues en workarounds

| Issue | Oorzaak | Workaround |
|---|---|---|
| `AMQPLAIN login refused` fout in OTS | Verkeerd wachtwoord of gebruiker niet aangemaakt | Controleer `rabbitmqctl list_users`; reset wachtwoord met `rabbitmqctl change_password ots NIEUW_WACHTWOORD` |
| Management UI niet bereikbaar | Plugin niet geactiveerd of firewall | `rabbitmq-plugins enable rabbitmq_management`; controleer ufw voor poort 15672 |
| RabbitMQ start niet na reboot | Erlang versie incompatibiliteit | Controleer `erl -version`; zorg voor compatibele Erlang versie |
| Hoog geheugengebruik | Veel berichten in queue zonder consumers | Voeg memory alarm in: `rabbitmqctl set_vm_memory_high_watermark 0.4` |
| Exchange bestaat al bij heruitvoer script | Idempotentie: bestaande exchange met andere eigenschappen | Verwijder exchange eerst via UI of API, dan opnieuw aanmaken |
| Berichten verloren na herstart | Exchanges niet duurzaam (`durable: false`) | Zorg dat alle exchanges met `"durable": true` zijn aangemaakt |
